# Code of conduct

This project adopts the [Contributor Covenant, version 2.1][covenant].

In short: be civil, assume good faith, and criticise work rather than people.

[covenant]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/

## One project-specific addition

Scientific claims here are meant to be attacked. Pointing out that a test is
vacuous, that a docstring overstates what the code does, or that a roadmap row
marked `done` is not — that is the most valuable contribution anyone can make,
and it will never be treated as hostile. The whole repository is organised
around making such claims cheap to falsify.

The reverse also holds: defending a claim by asserting it more confidently, or
by pointing at a passing test suite rather than at the specific test, is not a
response.

## Enforcement

Report conduct concerns through a private GitHub security advisory or by
contacting the repository owner directly. Reports will be handled discreetly.
